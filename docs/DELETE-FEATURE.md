# 删除功能说明

## 功能概述

为基础数据模块的位置管理和元数据配置添加了删除功能。

## 修改文件清单

### 前端
1. **API 层**
   - `frontend/src/api/location.js` - 添加 `deleteLocation(id)` 方法
   - `frontend/src/api/metadata.js` - 添加 `deleteMetadata(id)` 方法

2. **页面层**
   - `frontend/src/views/basic/location/index.vue` - 添加删除按钮和处理逻辑
   - `frontend/src/views/basic/metadata/index.vue` - 添加删除按钮和处理逻辑

### 后端
1. **Service 层**
   - `backend/src/main/java/com/rmm/service/LocationService.java` - 添加删除前的库存引用检查

## 功能特性

### 位置管理删除功能
- ✅ 删除按钮：红色 "删除" 按钮，位于操作列
- ✅ 确认对话框：删除前需确认
- ✅ 安全检查：检查该位置是否被库存记录使用
- ✅ 错误提示：如果位置被引用，显示错误信息并阻止删除

### 元数据配置删除功能
- ✅ 删除按钮：红色 "删除" 按钮，位于操作列
- ✅ 确认对话框：删除前需确认
- ✅ 成功提示：删除成功后显示提示并刷新列表

## 业务规则

### 位置管理
- 如果位置被库存记录引用（`stock` 表中的 `location_id`），则无法删除
- 删除失败时会提示："该位置已被库存记录使用，无法删除"

### 元数据配置
- 可以删除任何元数据项
- 删除后立即从列表中移除

## 测试方法

### 前端测试
1. 启动服务：
   ```bash
   ./scripts/start-all.sh start
   ```

2. 访问系统：http://localhost

3. 登录系统：
   - 用户名：admin
   - 密码：admin123

4. 测试位置管理删除：
   - 进入"基础数据" -> "位置管理"
   - 点击某个位置的"删除"按钮
   - 确认删除操作

5. 测试元数据配置删除：
   - 进入"基础数据" -> "元数据配置"
   - 点击某个元数据项的"删除"按钮
   - 确认删除操作

### API 测试
运行测试脚本（需要先处理验证码）：
```bash
./scripts/test-delete-api.sh
```

## 注意事项

1. 删除操作不可逆，请谨慎操作
2. 被引用的位置无法删除，需要先清理相关库存记录
3. 建议在生产环境中添加删除日志记录
